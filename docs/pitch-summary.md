# Pitch summary

I built an open-source treasury analyst that answers plain-English questions about a DAO's on-chain treasury, starting with the Uniswap DAO timelock. Every number comes from tested code over a pinned on-chain snapshot, every claim is checked against tool output before it's shown, and every answer links to the transactions behind it. It refuses investment advice and won't look up private wallets, and when the data can't answer something, it says exactly what is missing. On an 85-question eval with independently computed ground truth, it answered 88.7% of answerable questions correctly, against 6.5% for a model reading the raw transactions, and anyone can re-run the eval offline with one command. It runs as a CLI or Telegram bot, and pointing it at your DAO's treasury is a config change, so I'd be glad to set it up for your team: https://github.com/mhsh77/dao-treasury-analyst
